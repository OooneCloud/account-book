【李嘉星 · 组长项目骨架包】使用说明

一、包内文件(你负责的全部产出)
  app.py            Flask入口+全部路由(已接好 record/report/storage 的调用)
  requirements.txt  依赖清单(flask)
  .gitignore        忽略 data/、__pycache__/ 等
  seed.py           演示数据一键生成(演示前运行 python seed.py)
  templates/        index.html、stats.html 占位页(谢玲洁/王清源会直接覆盖)

二、你的操作步骤(全组第一个动手)
  1. 安装 Git:https://git-scm.com/download/win (一路下一步)
  2. GitHub 新建仓库 account-book(新建!勿与其他作业共用),Public
  3. Settings -> Collaborators 添加 5 位组员账号
  4. 本地首次推送(在解压出的文件夹里,加上 00~07 那些分工文档一起):
     git init
     git config --global user.name  "你的GitHub用户名"
     git config --global user.email "你的GitHub邮箱"
     git add .
     git commit -m "[core] 初始化Flask骨架和路由"
     git branch -M main
     git remote add origin https://github.com/<你的用户名>/account-book.git
     git push -u origin main
  5. 群里发仓库地址,通知全组 clone,并确认接口约定(00-总览文档)

三、之后的节点
  - 15:45 联调:合并各人的 PR(每人只动自己的文件,冲突找你)
  - 16:30 打 release:git tag v1.0 -> git push --tags -> GitHub 发布 Release
  - 演示脚本用 python seed.py 生成的12条数据,别现场录数据

四、红线
  - 每人 commit 必须用本人账号;你只动 app.py,README 归王清源
